# Оформление заказа

Кнопка «Оформить заказ» в корзине ведёт на `/checkout`. Там адрес доставки и сводка с итогом, который совпадает с итогом корзины.

## Проверки при оформлении

В таком порядке:

1. Учётная запись не ограничена, иначе «Оформление заказа недоступно для вашей учётной записи», см. [accounts-and-roles.md](accounts-and-roles.md).
2. Адрес не короче 10 символов, иначе «Укажите адрес доставки полностью: город, улица, дом». Введённый адрес сохраняется в поле.
3. Корзина не пуста, иначе «Корзина пуста».
4. Каждого товара на складе не меньше, чем в корзине, иначе ««Название»: на складе осталось N шт.», см. [cart-limits.md](cart-limits.md).

## После оформления

- Покупатель попадает на страницу заказа «Заказ №N оформлен».
- Остатки уменьшаются на количество из заказа.
- Корзина очищается, промокод снимается.

## Оплата

Онлайн-оплаты нет: заказ оплачивается при получении. Кнопки «Оплатить» на сайте нет и не должно быть.
