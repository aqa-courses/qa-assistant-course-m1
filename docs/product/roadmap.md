# Запланированное

Функции, которых сейчас нет. Обращения с такими просьбами — пожелания, их привязывают к пункту из этого списка.

| Функция | Статус |
|---|---|
| WELCOME500 только для первого заказа | в работе, см. [promo-welcome500.md](promo-welcome500.md) |
| Поиск по описанию товара | запланировано |
| Убрать промокод кнопкой в корзине | запланировано |
| Восстановление пароля | запланировано |
| Онлайн-оплата картой | исследуется |
| Отмена заказа покупателем | исследуется |
| Уведомления о снижении цены в избранном | после выхода избранного из беты |

Чего в этом списке нет — новые пожелания. Не планируются: регистрация без поддержки, снятие лимита 5 штук, суммирование промокодов, резервирование товара в корзине.
