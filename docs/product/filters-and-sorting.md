# Фильтры и сортировка

Фильтры применяются кнопкой «Найти» вместе с поисковым запросом.

## Фильтры

- **Категория** — одна или «Все категории».
- **Цена от / до** — в целых рублях, **границы включаются**: «до 990» показывает товар за 990 ₽. Фильтр смотрит на текущую цену, старая цена товаров со скидкой не учитывается.

Если «от» больше «до», результат пустой. Ошибкой это не считается.

## Сортировка

| Вариант | Порядок |
|---|---|
| По умолчанию | порядок добавления в каталог |
| Сначала дешёвые | по текущей цене по возрастанию |
| Сначала дорогие | по текущей цене по убыванию |
| По названию | по алфавиту |

Сортировки по популярности, рейтингу и новизне нет.
