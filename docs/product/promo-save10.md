# Промокод SAVE10

**10% на товары без скидки.**

## Правила

- Скидка считается только с суммы строк, у которых **нет** метки «Скидка» (старой цены). Товары со скидкой в корзине остаются, но в расчёт SAVE10 не входят. Двойная скидка на один товар не даётся.
- Если в корзине только товары со скидкой, скидка 0 ₽ и пояснение «SAVE10 не действует на товары со скидкой».
- Минимальной суммы заказа нет.
- Код многоразовый, ограничений на число заказов нет.

## Примеры

| Корзина | Скидка |
|---|---|
| USB-C хаб 2 490 ₽ | −249 ₽ |
| USB-C хаб 2 490 ₽ + Беспроводная мышь 1 990 ₽ (со скидкой) | −249 ₽, мышь не учитывается |
| только Беспроводная мышь 1 990 ₽ (со скидкой) | 0 ₽ и пояснение |
| 2 × USB-C хаб = 4 980 ₽ | −498 ₽ |

Итог в корзине всегда уменьшается на размер скидки, см. формулу в [cart.md](cart.md).

Товары со скидкой сейчас: Беспроводная мышь, Монитор 24", Наушники с шумоподавлением.
