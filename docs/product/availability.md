# Доступность и страницы ошибок

## Страницы ошибок

| Код | Когда | Текст |
|---|---|---|
| 404 | нет товара или заказа | «Товар не найден», «Заказ не найден» |
| 503 | сервис недоступен | «Сервис временно недоступен. Попробуйте позже.» |

На странице ошибки есть кнопка «В каталог».

## Недоступность

503 на всех страницах означает недоступность сервиса целиком, обычно базы данных. Это инцидент: обращения о нём не разбираются по одному, а привязываются к инциденту. API в это время тоже отвечает 503 с телом `{"status": "degraded", "detail": "Database unavailable"}`.

`GET /health` показывает состояние: `{"status": "ok", ...}` или 503 при недоступности.

Целевая доступность — 99,5% в месяц. Плановых окон обслуживания с недоступностью сайта нет.
