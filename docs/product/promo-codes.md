# Промокоды

Промокод вводится в корзине, кнопка «Применить».

## Общие правила

- **Действует один промокод.** Новый код **заменяет** предыдущий, скидки не суммируются. Это касается любых сочетаний, включая SAVE10 + WELCOME500.
- Регистр не важен: `save10` = `SAVE10`. Пробелы по краям игнорируются.
- Неизвестный код: «Промокод не найден», действующий промокод при этом не меняется.
- Применённый код показывается под полем: «Действует: SAVE10».
- Промокод сохраняется в корзине до оформления заказа, даже если корзину очистить и собрать заново.
- Если условия кода не выполняются, код остаётся применённым, скидка 0 ₽, а под полем объясняется причина. Как только условия выполнятся, скидка появится сама.
- Убрать промокод в интерфейсе нельзя, только заменить другим. В API для этого есть `DELETE /api/cart/promo`.

## Действующие коды

| Код | Что даёт | Спецификация |
|---|---|---|
| SAVE10 | 10% на товары без скидки | [promo-save10.md](promo-save10.md) |
| WELCOME500 | 500 ₽ на заказ от 3 000 ₽ | [promo-welcome500.md](promo-welcome500.md) |

Скидка вычитается из суммы товаров **до** расчёта доставки, см. [shipping.md](shipping.md).
