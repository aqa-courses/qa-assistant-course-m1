# Учётные записи и роли

У каждой учётной записи одна роль.

| Роль | Что может |
|---|---|
| `customer` — покупатель | всё: каталог, корзина, промокоды, оформление заказа, история заказов |
| `restricted` — ограниченная | смотреть каталог, собирать корзину, применять промокоды. **Оформлять заказы не может** |
| `admin` — администратор | то же, что покупатель. Отдельной панели администратора в интерфейсе пока нет |

## Ограниченная учётная запись

Роль `restricted` выдаёт служба безопасности, например при проверке подозрительной активности или неподтверждённых платёжных данных. Покупателю не нужно терять корзину на время проверки, поэтому корзина работает как обычно.

При попытке оформить заказ показывается сообщение «Оформление заказа недоступно для вашей учётной записи», API отвечает `403`. В профиле такой учётной записи видна плашка «Ограниченная учётная запись: оформление заказов недоступно».

Это ожидаемое поведение, а не ошибка. Снять ограничение может только служба безопасности по обращению в поддержку.

## Заблокированная учётная запись

Заблокированная учётная запись не может войти, см. [login.md](login.md).
