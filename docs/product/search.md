# Поиск

Поле поиска в каталоге ищет **только по названию товара**.

## Правила

1. **Минимум 2 символа.** Запрос из одного символа не фильтрует каталог: показываются все товары и подсказка «Введите не меньше 2 символов для поиска». Так сделано, чтобы запрос «м» не возвращал половину каталога под видом результата поиска.
2. **Подстрока.** «хаб» находит «USB-C хаб», «тор» находит оба монитора.
3. **Регистр не важен**, в том числе для кириллицы: «МОНИТОР» и «монитор» дают одинаковый результат.
4. **Описание не участвует.** Запрос «IPS» ничего не находит, хотя IPS упомянут в описаниях мониторов. Поиск по описаниям в планах, см. [roadmap.md](roadmap.md).
5. **Без морфологии и опечаток.** «клавиатуры» не найдёт «Механическая клавиатура», «мыш» найдёт, а «мышка» — нет. Буквы «е» и «ё» считаются разными.

Пустой результат: «Ничего не найдено. Попробуйте изменить запрос.»

## Скорость

Целевое время ответа поиска — до 1 секунды. Ответ дольше 3 секунд считается дефектом производительности.

Поиск совмещается с фильтрами и сортировкой, см. [filters-and-sorting.md](filters-and-sorting.md).
