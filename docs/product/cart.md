# Корзина

Корзина хранится на аккаунте: она одна на всех устройствах и не пропадает после выхода.

## Строки корзины

Название, цена, количество, сумма строки и ссылка «Удалить». Количество меняется прямо в поле, пересчёт происходит сразу. Количество 0 удаляет строку. Ограничения на количество — в [cart-limits.md](cart-limits.md).

## Сводка

| Строка | Как считается |
|---|---|
| Товары | сумма строк по текущим ценам |
| Скидка | по промокоду, см. [promo-codes.md](promo-codes.md); без промокода «0 ₽» |
| Доставка | см. [shipping.md](shipping.md); «бесплатно», если доставка не платная |
| **Итого** | **Товары − Скидка + Доставка** |

Пример: USB-C хаб за 2 490 ₽ и промокод SAVE10. Товары 2 490 ₽, скидка −249 ₽, доставка 299 ₽, итого **2 540 ₽**.

Итого в корзине, на странице оформления и в заказе всегда совпадает. Любое расхождение — дефект.

## Счётчик в шапке

Число рядом со ссылкой «Корзина» — **количество штук**, а не строк: два хаба и одна мышь дают «3». Пустая корзина счётчик не показывает.

## Цены

Корзина всегда считает по текущим ценам каталога. Если цена изменилась после добавления, корзина покажет новую. Цена фиксируется только в момент оформления заказа, см. [orders.md](orders.md).
