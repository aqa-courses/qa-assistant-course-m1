# Сессии

После входа браузер получает cookie сессии `sid` (HttpOnly, SameSite=Lax). Для REST API тот же токен передаётся в заголовке `Authorization: Bearer <token>`.

- Сессия живёт до выхода по кнопке «Выйти». Автоматического истечения по времени нет.
- Можно войти одновременно с нескольких устройств. Вход на новом устройстве не завершает старые сессии.
- «Выйти» завершает только текущую сессию.
- Корзина хранится на аккаунте, а не в браузере, поэтому на всех устройствах она одна и та же, см. [cart.md](cart.md).

Страницы корзины, оформления, заказов и профиля без сессии перенаправляют на вход и после входа возвращают обратно. Каталог и карточки товаров доступны без входа, но кнопка «В корзину» тогда ведёт на вход.
