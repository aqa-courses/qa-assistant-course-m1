# Shoplite: учебный стенд

Маленький интернет-магазин, который тестируют агенты курса. Его можно сломать по команде, чтобы у ассистента было что находить, чинить и классифицировать.

## Запуск

```bash
docker build -t shoplite .
docker run --rm -p 8000:8000 shoplite
# или без Docker:
pip install -r requirements.txt
uvicorn app.main:app --port 8000
```

Открой http://localhost:8000. Документация API: http://localhost:8000/docs.

| Пользователь | Пароль | Особенность |
|---|---|---|
| alice@example.com | password123 | обычный покупатель |
| bob@example.com | password123 | обычный покупатель |
| restricted@example.com | password123 | не может оформить заказ |
| locked@example.com | password123 | заблокирован, не может войти |
| admin@example.com | admin123 | администратор |

## Флаги поломок

Задаются переменными окружения при старте или на лету через `POST /__chaos`:

```bash
curl -X POST localhost:8000/__chaos -H 'Content-Type: application/json' -d '{"ui_version": 2}'
```

| Переменная | Поле в `/__chaos` | Что ломает | Класс в RCA |
|---|---|---|---|
| `UI_VERSION=2` | `ui_version` | переименованы `data-test`, корзина свёрстана карточками | `ui_change` |
| `BUG_CART_TOTAL=1` | `bug_cart_total` | итог корзины не учитывает скидку промокода | `product_bug` |
| `FLAKY_SEARCH=0.3` | `flaky_search` | поиск с вероятностью p отвечает с задержкой 0–5 с | `flaky_test` |
| `DB_DOWN=1` | `db_down` | страницы, API и `/health` отвечают 503 | `infrastructure` |
| `FEATURE_WISHLIST=1` | `feature_wishlist` | появляется «Избранное», на которое нет тестов | дыра в покрытии |

## Служебные эндпоинты

- `GET /health`: состояние (503 при `DB_DOWN`).
- `GET|POST /__chaos`: посмотреть или изменить флаги.
- `POST /__reset`: вернуть сид-данные; с `?flags=true` заодно вернуть флаги к значениям из окружения.
- `GET /__crawl`: карта `data-test` элементов по страницам с учётом текущих флагов. Её использует агент покрытия.

Если задан `CHAOS_TOKEN`, эндпоинты `/__*` требуют заголовок `X-Chaos-Token`.

## Правила, которые выглядят как баги, но так задумано

Они описаны в документации продукта (`docs/product`), чтобы агенту триажа было что процитировать:

- не больше 5 штук одного товара в корзине (или меньше, если меньше на складе);
- SAVE10 не действует на товары со скидкой;
- промокод один: новый заменяет предыдущий;
- поиск идёт только по названию и начинается с 2 символов;
- доставка бесплатная от 5 000 ₽ после скидки;
- ограниченная учётная запись может собрать корзину, но не оформить заказ.

## Тесты стенда

```bash
pip install -r requirements-dev.txt
pytest
```

Они проверяют, что каждый флаг ломает ровно то, что заявлено, иначе упражнения курса будут врать.
