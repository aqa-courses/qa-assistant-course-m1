# QA-ассистент на Google ADK — учебный репозиторий

Репозиторий курса: за 8 модулей вы собираете ассистента QA-инженера на [Google ADK](https://google.github.io/adk-docs/). Ассистент разбирает падения CI, чинит автотесты, триажит обращения поддержки и работает в продакшене. Всё — на учебном магазине Shoplite, который можно ломать по команде.

## Что внутри

| Папка | Что это |
|---|---|
| [shoplite/](shoplite/) | учебный стенд: магазин на FastAPI с флагами поломок |
| [autotests/](autotests/) | 15 e2e-тестов стенда на Playwright + TypeScript |
| [docs/product/](docs/product/) | спецификации магазина, по ним работает триаж |
| [fixtures/](fixtures/) | тест-кейсы и 40 тикетов поддержки с эталонной разметкой |
| [assistant/](assistant/) | ассистент — его вы и пишете |
| [tests/](tests/) | автопроверка заданий; без модели и без сети |
| [modules/](modules/) | задания модулей |

## Как проходить курс

Каждый модуль — пара веток:

- `mNN-start` — заготовка: код с `TODO` и тесты, которые пока падают;
- `mNN-solution` — эталонное решение. Подсматривать можно, но после своей попытки.

```bash
git switch m01-start
# решаете задания из modules/m01/README.md, пока не позеленеет:
pytest tests/unit
```

Решение сдаётся пулл-реквестом в ваш репозиторий: GitHub Actions прогоняет автопроверку, а я делаю код-ревью. Следующий модуль начинается с `git merge origin/m02-start`. Если отстали, начните с `m01-solution`.

## Быстрый старт

Нужны Python 3.11+, Docker, Node.js 24 (для автотестов) и ключ Claude API ([platform.claude.com](https://platform.claude.com/settings/keys)). Бесплатного уровня у API нет: пополните баланс на несколько долларов, на весь курс этого хватит с запасом.

```bash
cp .env.example .env              # ANTHROPIC_API_KEY, GITHUB_REPO, GITHUB_TOKEN
python -m venv .venv && . .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e ".[dev]"

docker build -t shoplite shoplite && docker run --rm -p 8000:8000 shoplite   # стенд на :8000
adk web --port 8080 assistant/agents                                          # чат с агентами на :8080
```

Агентам нужен ваш форк этого репозитория на GitHub: они читают его прогоны Actions и файлы.

## Сколько стоит модель

Автопроверка не тратит токены: вместо Claude в тестах работает `ScriptedLlm`, который отвечает по сценарию. Токены тратятся только когда вы сами говорите с агентом в `adk web`.

Все агенты по умолчанию работают на Claude Haiku 5.5: $0,10 за миллион входных токенов и $0,50 за миллион выходных. Агенту, которому этого мало, можно дать Claude Sonnet 5.5 ($2 / $10) одной переменной: `AGENT_MODEL_<ИМЯ_АГЕНТА>=claude-sonnet-5-5`. Каким агентам это нужно, вы проверите на eval в модуле 7. Лимит на сессию задаёт `SESSION_TOKEN_BUDGET` (по умолчанию 200 000): зациклившийся агент остановится на нём, а не на вашем счёте.

Сколько уходит по модулям. Замер на Claude Haiku 5.5 по эталонным решениям, с учебными данными вместо настоящего GitHub; один прогон каждого действия:

| Модуль | Что тратит токены | Один прогон | На модуль, с запасом |
|---|---|---|---|
| 1 | разговор с `github_agent`, 4 вопроса | 52 тыс. токенов, $0,007 | $0,05 |
| 2 | разговор с `root`, 5 вопросов; то же с `fat_agent` для сравнения | 163 тыс., $0,02 | $0,10 |
| 3 | то же через MCP, плюс `explorer_agent` в браузере | отдельно не измерялось: ответ инструмента обрезается до 20 000 символов | $0,10 |
| 4 | автоматизация кейса: тест, прогон, самопроверка | 92 тыс., $0,01 | $0,10 |
| 5 | разбор одного упавшего прогона | 3–4 тыс., $0,001 | меньше $0,01 |
| 6 | триаж всех 40 тикетов корпуса | 153 тыс., $0,03 | $0,30 — корпус придётся прогнать раз десять |
| 7 | eval маршрутизации (18 кейсов) и ревью (6 кейсов) | 55 тыс., $0,01 | $0,10 |
| 8 | ничего нового: те же агенты в `docker compose` | — | $0,05 |

Весь курс на Haiku укладывается примерно в доллар. Sonnet дороже в 20 раз за токен: если отдать ему, например, судью триажа, один прогон корпуса обойдётся в $0,5–0,6. Свой расход смотрите во вкладке State в `adk web` (`usage:total_tokens`) и в разделе Usage консоли Claude.
