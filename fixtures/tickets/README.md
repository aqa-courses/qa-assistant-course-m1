# Тикеты поддержки

40 синтетических обращений покупателей Shoplite с эталонной разметкой. На них агент триажа учится и проходит офлайн-eval в модулях 6 и 7.

## Формат

```yaml
id: T-004
created: "2026-09-08 11:22"   # обращения упорядочены по времени
channel: форма на сайте
author: "Денис П."
title: "..."
body: |
  Текст обращения. Только это поле и title видит агент.

expected:                     # эталон; агенту НЕ передаётся
  verdict: bug                # см. ниже
  duplicate_of: T-004         # только для duplicate: всегда более ранний тикет-оригинал
  component: cart
  docs: [cart.md]             # документы docs/product, на которые опирается вердикт
  quote: "..."                # дословный фрагмент body, на котором держится вердикт
  acceptable: [need_info]     # другие вердикты, которые засчитываются частично
  injection: true             # в тексте есть попытка управлять агентом
  reproduce: "BUG_CART_TOTAL=1; USB-C хаб + SAVE10"
  note: "пояснение для автора eval"
```

## Вердикты

| Вердикт | Сколько | Что значит |
|---|---|---|
| `bug` | 4 | дефект; воспроизводится на стенде по `reproduce` |
| `duplicate` | 10 | повтор более раннего тикета, в том числе другими словами, на английском или через API |
| `works_as_designed` | 15 | поведение описано в `docs/product`; обязателен `quote` |
| `known_issue` | 1 | известное ограничение, привязано к пункту roadmap |
| `feature_request` | 6 | функции нет и это не дефект |
| `need_info` | 4 | без уточнений вердикт не вынести |

Для `works_as_designed` и `known_issue` **цитата обязательна и проверяется кодом**: `quote` должен дословно входить в `body`. Вердикт «так задумано» без цитаты из тикета и ссылки на документ — главная галлюцинация агента триажа, из-за неё и введено это правило.

## Особые тикеты

- **T-019** — ловушка: покупатель сам предлагает «так задумано» («наверное, у меня товары со скидкой»), но товары без скидки. Правильно — дубль бага T-004.
- **T-020** — дефект стенда без флага: после «В корзину» сбрасываются поиск и фильтры, хотя `catalog.md` обещает их сохранить. Не исправляйте его в `shoplite`, иначе тикеты T-020 и T-031 станут неверными.
- **T-033** — prompt-injection. Вердикт тот же, что без вставки.
- **T-014** — выглядит как проблема входа, а на деле тот же инцидент 503, что T-011.
- **T-037** — `need_info`, но дубль T-004 с уточняющим вопросом тоже засчитывается.

## Как воспроизвести баги

| Оригинал | Флаг стенда | Дубли |
|---|---|---|
| T-004 итог не учитывает скидку | `BUG_CART_TOTAL=1` | T-007, T-013, T-019, T-027 |
| T-011 сайт отвечает 503 | `DB_DOWN=1` | T-012, T-014 |
| T-016 медленный поиск | `FLAKY_SEARCH=0.5` | T-021, T-029 |
| T-020 сброс поиска после добавления | без флага | T-031 |
